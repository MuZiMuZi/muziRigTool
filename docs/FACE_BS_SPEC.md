# 面部修型（BS）命名与雕刻要点

> 来源：主人给的修型清单与雕刻说明。代码侧只认名字，形状由人雕。
> 命名一律驼峰，不加 side / index；左右共用同一个目标体，按权重分侧驱动。

---

## 一、基础修型

### 眉毛

| 名字 | 要点 |
|---|---|
| `browUp` | 抬头纹：褶皱厚、宽，不要锋利；外围看头部是圆弧形 |
| `browDown` | 向下挤压：眉头鼓起褶皱，宽厚；眉毛尽量保持一条直线，下压幅度盖住半个眼睛；有鱼尾纹则加深 |
| `browSqueeze` | 向内收：皱纹从两侧平滑往中间过渡，可不完全镜像；宽厚有过渡，侧面看圆弧，有肌肉向下压的感觉 |

### 眼睛

| 名字 | 要点 |
|---|---|
| `eyeUpWide` | 睁大：往上看得到瞳孔，范围大但不动到眉弓；注意和眼球的距离，要包裹住 |
| `eyeDownWide` | 下眼睑睁大 |
| `eyeUpClose` | 闭合：侧面看是干净的弧形，完全闭上，沿眼球方向运动 |
| `eyeDownClose` | 下眼睑闭合 |
| `eyeUpMid` | 半闭（上） |
| `eyeDownMid` | 半闭（下） |

### 鼻子

| 名字 | 要点 |
|---|---|
| `sneer` | 冷笑：靠近眉头处向外挤压，鼻翼两侧肌肉往上、往内挤；两边圆润过渡，褶皱可不完全对称，宽厚、圆弧 |
| `squint` | 眯眼：眼皮下肌肉往上挤，向鼻翼和脸颊内收；下眼皮也有挤压感、变厚，卧蚕圆弧；鼻翼两侧侧面看是圆弧肉感 |

### 脸颊

| 名字 | 要点 |
|---|---|
| `cheekOut` | 往外鼓 |
| `cheekIn` | 由 `cheekOut` 反向得到 |
| `cheekUp` | 上提 |
| `cheekDown` | 下压 |

**做法**：圆球 + 头部，先选头再选球做 `shrinkWrap`，刷影响范围；
projection 改 **vertex normal**，勾 **reverse**；移动球体调整形状。
`cheekIn` 直接用 `cheekOut` 反向。

### 嘴巴

| 名字 | 要点 |
|---|---|
| `mouthSmile` | 整体上提，苹果肌上鼓，弧线圆润；法令纹更明显；嘴角平滑不锋利、不进太多 |
| `mouthFrown` | 嘴角向下呈圆弧；人中到嘴角降得慢，两侧肌肉堆叠有肉感；鼻翼跟随往下，过渡要平滑 |
| `mouthStretch` | 拉伸（不同宽度嘴唇的 9 个形状之一） |
| `mouthNarrow` / `mouthNarrowUp` / `mouthNarrowDown` | 两侧往内挤，沿牙齿外轮廓；嘴唇修饱满、微微前突但不多；整体变宽变厚、更圆 |
| `mouthCornerUp` / `mouthCornerDown` | 嘴角上下：中间嘴唇保持圆弧，唇珠不要因为嘴角动作变尖 |
| `mouthSideLeft` | 歪嘴：鼻子跟随，弧形轨迹（从底下看）；嘴唇顺牙齿外侧转；法令纹挤出、肉感鼓出；另一侧法令纹拉长，脸颊不要往外影响太多 |

### 嘴唇

| 名字 | 要点 |
|---|---|
| `lipRollOut` | 外翻：翻后仍保留嘴唇结构，线要卡死；嘴角处过渡，越靠嘴角翻转幅度越小；注意弧度和饱满肉感 |
| `lipRollIn` | 内收（抿嘴）：外面看是有弧度的圆；中间缝保持平，阴影一致；内翻时保持肉感，坑洼补齐 |
| `lipPount` | 整体下唇往上提、往外划出 |
| `lipPountLeft` | 下唇向一侧运动，以嘴角为终点，动量逐渐减小 |

## 二、融合修型（叠权重，不单独雕）

| 名字 | 公式 | 意图 |
|---|---|---|
| `eyeExpand` | `browUp + eyeUpWide + eyeDownWide` | 惊讶/吃惊：瞳孔放大、眉毛上挑 |
| `eyeCrush` | `browDown + sneer + squint + eyeUpClose` | 眯眼/皱眉 |

---

## 三、代码约定

- 目标体命名：`bs_<part>_<name>_001`，例如 `bs_lf_brow_browUp_001`。
- 驱动：只由**表情面板 / 次级控制器**驱动（driven key），不接关节旋转的 pose driver。
- 融合修型不建独立目标体，按公式把基础权重相加；多路相加要 `clamp 0-1`。
- 左右共用：同一目标体，左右两侧走各自控制器的权重。
